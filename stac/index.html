MarineSensitivity STAC catalog

A SpatioTemporal Asset Catalog of the species distribution models behind the Marine Sensitivity Toolkit, one collection tree per release, described with the sdm extension.

  • catalog.json — the root catalog (static JSON)
  • Browse it in STAC Browser
  • stac-api.marinesensitivity.org — the searchable STAC API, one Item per model
library(rstac)
cat <- read_stac("https://marinesensitivity.org/stac/catalog.json")

# python
import pystac
cat = pystac.Catalog.from_file("https://marinesensitivity.org/stac/catalog.json")

The collections and items are served from file.marinesensitivity.org/stac; this address is an alias of the root. MarineSensitivity.org
